Freshora front-page feature assets
=================================

Included:
- fresh-products-leaf.svg
- fast-delivery-lightning.svg
- happier-you-heart.svg
- feature-divider.svg
- supplied-reference-strip.png

The SVG files are vector assets and therefore stay sharp when rendered at different sizes.

IMPORTANT:
The SVG icons are clean vector recreations based on the supplied 508x103 reference strip. They are not extracted raster crops, because raster crops from the supplied screenshot would become blurry when enlarged.

For an exact production match, if the Freshora repository contains the original SVG/icon files, prefer those originals over these reference-based vectors.

Recommended front-page labels:
FRESH
PRODUCTS

FAST
DELIVERY

HAPPIER
YOU

Use real text with the repository's correct Freshora font instead of turning the text into a bitmap.
